Example Viewer Pack

This pack is displayed inside Tobkiri Launcher.

This is a minimal example of a Pack that uses the viewer:display capability to render its frontend in the Tobkiri Launcher sandbox WebView.

How it works

  1. The Pack requests viewer.display capability
  2. Kernel checks Grant via capability_grant_manager
  3. Kernel issues a short-lived token and returns web_mount_url
  4. Tobkiri Launcher loads this HTML inside a sandbox WebView
