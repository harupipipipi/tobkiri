# Tobkiri Launcher start guide (legacy URL)

The current startup and troubleshooting guide is
[`tobkiri_launcher_start.md`](./tobkiri_launcher_start.md). This filename remains
so existing links keep working during the product-name transition.

For a fresh source checkout, complete [repository Setup](../../README.md#setup)
and use the foreground [Launcher development workflow](./tobkiri_launcher_start.md#build-and-start-from-source).
Keep that process running during the session. Verify Profile activation and
PackVM readiness separately before launching Defaults.

Older instructions at this URL described automatic approval, manual capability
grants and standalone Python/Pack launch paths. They are not the current Pack v4
startup workflow. Do not use those recipes to bypass Launcher-owned native
approval or verified activation. A browser panel, successful Python import or
old screenshot does not prove an installed/native launch.
