# Tobkiri Surface Renderers

Optional data-only RendererPack for `tobkiri.ui.surface-renderer.v1`, API `1.0.0`.
Standard and compact manifests select finite implementations shipped by the
Application. They contain no executable code, Host operations, network,
credentials, permissions or filesystem access.

Select this Pack explicitly and reference `tobkiri.surface-renderer.standard` or
`tobkiri.surface-renderer.compact` from a validated Surface Template. The Host
must compile and verify the selected artifact/index first. Missing or invalid
selection remains unavailable.

`integration-input.v1.json` is adoption input, not installed execution evidence.
No production resource picker or alternate native renderer is claimed. See
Defaultspack's `docs/surface_templates_v1.md` for the wire and validation limits.
