Tobkiri Browser Companion

Control exactly when Tobkiri may connect to this browser and which sites it may use.

Review browser access before enabling

When enabled, the paired local Tobkiri instance may receive metadata for allowed tabs, including each page title and URL. Commands may read page content and accessibility labels, capture the visible page, navigate, click, type, press keys, or scroll on allowed sites.

Polling sends that allowed-tab metadata to the local bridge even when no command is waiting. Browser-internal pages, file URLs, incognito tabs, denied sites, and sites without browser permission remain blocked.
