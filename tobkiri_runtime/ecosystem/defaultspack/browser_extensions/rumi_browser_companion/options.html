Tobkiri Browser Companion

Configure the local Tobkiri bridge endpoint and pairing token used by this browser.

Current-page access

After pairing, the companion can inspect page content and act on supported web pages in this profile only when Tobkiri sends an approved browser command. Browser-internal pages and other restricted URLs remain unavailable.

Capabilities

  • Periodic bridge poll with browser metadata and tabs summary
  • Local browser/profile metadata with installation id and profile label
  • Tab operations: list, select, navigate, capture visible tab
  • Semantic DOM snapshot with element id, role, labels, nearby text, geometry, and action hints
  • Element actions by `element_id`, CSS selector, text, accessible name, role, semantic id, or nearby text
