Tobkiri Browser Companion

Connection, access, and safety help for this browser profile.

Status labels

  • Connected: the latest local bridge poll succeeded.
  • Connecting: a poll is in progress or has not completed yet.
  • Setup required: the server URL or pairing token is missing.
  • Connection error: the configured local bridge did not respond.

Current-page access

The companion can inspect page content and act on supported web pages in this browser profile only when Tobkiri sends an approved browser command. Browser-internal pages and other restricted URLs do not allow extension access.

Safety

  • Pair only with a local Tobkiri server you control.
  • Do not share the pairing token.
  • The pairing token stays in this browser profile's local extension storage.
  • Use the toolbar popup to check the endpoint and profile before running commands.
