# MiMo Coding Company

This bundle is the stable memory for the MiMo-first coding harness.

Core rules:

- Start from one small high-value coding task, verify it, then widen scope.
- If a needed tool or skill is missing, build the smallest viable version instead of stopping.
- Prefer evidence-backed browser/computer QA over broad complaints, then turn each real bug into a fix task for MiMo Pro.
- Create issues only for evidence-backed bugs that need external tracking or are blocked from being fixed in the loop.
- Keep prompts short and operational.
- Record useful findings so later loops improve instead of repeating setup work.
