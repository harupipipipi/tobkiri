# Rumi AI Routing Pack

This pure service matches explicit model descriptors against modality, tool,
thinking, context, surface, residency, availability, health, capability, and
cost requirements. It discovers nothing, executes no provider, reads no
credential, and contains no concrete provider or provider-pack branch.

Ordering is deterministic and diagnostics retain every excluded candidate and
reason. Stale health becomes unknown; unknown cost is rejected when a maximum
cost policy is active.

Validation was not executed by the implementation agent. Independent testing
is required before merge, including ordering, every exclusion reason, stale
health, unknown cost, provider removal, and replacement routing providers.
